# 🌱 Eco-Friendly Product Marketplace Website

A responsive, client-side e-commerce web application designed to promote sustainable products with dynamic shopping cart logic, cash-on-delivery (COD) checkout simulation, and local storage data persistence.

---

## ✨ Key Features

* **🛍️ Product Showcase & Filtering:** Interactive catalog displaying eco-friendly products with responsive card layouts.
* **🛒 Dynamic Cart System:** Real-time item additions, quantity updates, total price calculation, and local storage state management.
* **💳 COD Order Checkout:** Simulated Cash-On-Delivery checkout flow with order confirmation feedback.
* **🌙 Dark Mode & Responsive UI:** Seamless UI theme toggle with persistent display preferences across desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Data Persistence:** Web Storage API (`localStorage`)
* **Developer Tools:** VS Code, Git, GitHub
